## TokenViewer v0.3.16

### QwenWork support — macOS Apple silicon, Intel, and Windows x64

- Track QwenWork token usage from its local Flash harness database under `~/.qwenwork/`, including input, output, reasoning, and cache read/write tokens.
- Read live SQLite WAL updates, collect messages once they complete, and avoid double-counting repeated syncs or duplicate session/step totals.
- Detect QwenWork installations and manage Skills in `~/.qwenwork/skills`, separately from Qwen Code.
- Display the QwenWork application icon extracted from the installed app on macOS and Windows.

Subscription quota tracking is not included in this release.

### Downloads

- Apple silicon, macOS 14+: `TokenViewer.dmg`, `TokenViewer-Installer.pkg`, or `TokenViewer-0.3.16-macOS-arm64.zip`.
- Intel, macOS 14+: `TokenViewer-0.3.16-macOS-x64.dmg`, `TokenViewer-0.3.16-macOS-x64-Installer.pkg`, or `TokenViewer-0.3.16-macOS-x64.zip`.
- Windows 10/11 x64: extract `TokenViewer-0.3.16-Windows-x64.zip` and run `TokenViewer.exe`.

macOS packages use self-signed packaging. The Windows build is unsigned.
