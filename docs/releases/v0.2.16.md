## TokenViewer v0.2.16

This release improves model attribution for ChatGPT usage imported from isolated host applications.

### 🐛 Fixes

- Resolves host-provided model aliases to their actual upstream model names, including DeepSeek models used through Antigravity Cockpit.
- Uses each isolated ChatGPT data directory's model catalog while safely sharing only unambiguous mappings across directories.
- Migrates previously imported alias-based usage into the resolved model without duplicating token totals.

### 📦 Installation

**Recommended:** Download `TokenViewer.dmg`
- Drag `TokenViewer.app` to `/Applications`
- First launch: System Settings -> Privacy & Security -> Open Anyway
- Requires macOS 14 (Sonoma) or later

**Alternative:** Download `TokenViewer-Installer.pkg`
- Double-click to install -> app is placed in `/Applications`
- The installer updates the existing app in place and opens it after installation
- Requires macOS 14 (Sonoma) or later
