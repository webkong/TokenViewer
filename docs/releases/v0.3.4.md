## TokenViewer v0.3.4

This release improves private Skills repository authentication and makes frequently used Skill actions easier to access.

### 🛠 Fixes

- Skills Git Sync now supports `GH_TOKEN` and `GITHUB_TOKEN`, while continuing to use saved credentials for other Git providers.
- Pull and Push availability now follows the actual resolved credential instead of a separate saved-state flag.
- Git authentication failures, including authentication replay errors, now provide actionable guidance instead of raw libgit2 messages.

### ✨ Improvements

- Skill environment-variable settings are available directly from the selected Skill's detail panel.
- View Content and Open in Finder now share one compact action row.
