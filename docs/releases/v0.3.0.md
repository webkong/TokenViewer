## TokenViewer v0.3.0

This release introduces the Sessions browser — browse, rename, and resume past AI conversations in your favorite terminal — alongside a redesigned Usage dashboard and Skills workspace.

### ✨ Highlights

- **New Sessions page**: scans local conversation files from Claude Code, ChatGPT (Codex), Grok, OpenCode, Kiro, GitHub Copilot, Gemini, and Hermes.
- Session titles are generated automatically (agent title → your first prompt → project + time), and any session can be renamed persistently.
- **Resume in one click**: relaunch any session in Terminal, iTerm2, Ghostty, cmux, or Orca, at its original working directory, with strict validation and shell-safe quoting.
- **Per-agent YOLO mode**: configure auto-approval flags for 25 agents individually in Settings (defaults mirror Orca's permission map), with a first-time risk confirmation.
- Session stats: model, tokens, cost, turns, edits, and active duration.
- Redesigned Usage dashboard with per-agent trend filtering, a custom date range picker, and all-time project usage details.
- Redesigned Skills workspace with a unified control style across the app.
- Codex scanning now covers `archived_sessions` folders and isolated Codex homes (Orca, Antigravity Cockpit, and other hosts).

### 🐛 Fixes

- Improved dashboard and tab switching responsiveness.
- Sessions list renders cached results immediately while scanning in the background; unchanged files are skipped on rescans.
