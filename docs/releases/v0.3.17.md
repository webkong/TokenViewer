## TokenViewer v0.3.17

- **macOS and Windows** — Read token usage from current Antigravity transcripts, backfill records missed by earlier versions, and avoid counting the same model response twice. Gemini 4 Neon cost estimates use Google's API rates.
- **macOS and Windows** — Manage global Antigravity Skills in `~/.gemini/config/skills`. TokenViewer migrates links it previously created in the old default location when the new destination is available.
- **macOS** — Show the signed-in Antigravity plan and the remaining weekly and five-hour quotas for Gemini and Claude/GPT, with reset countdowns when available. Keep the Antigravity desktop app running and signed in to refresh these values.

### Downloads

- Apple silicon, macOS 14+ — `TokenViewer.dmg`, `TokenViewer-Installer.pkg`, or `TokenViewer-0.3.17-macOS-arm64.zip`.
- Intel, macOS 14+ — `TokenViewer-0.3.17-macOS-x64.dmg`, `TokenViewer-0.3.17-macOS-x64-Installer.pkg`, or `TokenViewer-0.3.17-macOS-x64.zip`.
- Windows 10/11 x64 — Extract `TokenViewer-0.3.17-Windows-x64.zip` and run `TokenViewer.exe`.
