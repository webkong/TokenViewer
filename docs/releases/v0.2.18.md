## TokenViewer v0.2.18

This release improves model attribution, pricing accuracy, and terminology across the macOS app.

### ✨ Improvements

- Distinguishes AI coding agents from model providers throughout usage views and settings.
- Adds dynamically refreshed LiteLLM pricing with a local 24-hour cache and curated overrides.
- Improves model-provider icons while preserving the concrete model names recorded in local logs.

### 🐛 Fixes

- Prevents Codex sessions from being attributed to unrelated routed model names.
- Preserves Claude conversation-to-model attribution across incremental syncs and model switches.
- Falls back to built-in cache pricing when an upstream pricing entry omits individual fields.
- Correctly normalizes Antigravity model routes without stripping the underlying Claude or GPT family.

### 📦 Installation

**Recommended:** Download `TokenViewer.dmg`
- Drag `TokenViewer.app` to `/Applications`
- First launch: System Settings -> Privacy & Security -> Open Anyway
- Requires macOS 14 (Sonoma) or later

**Alternative:** Download `TokenViewer-Installer.pkg`
- Double-click to install -> app is placed in `/Applications`
- The installer updates the existing app in place and opens it after installation
- Requires macOS 14 (Sonoma) or later
