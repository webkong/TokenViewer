## TokenViewer v0.2.15

This release improves ChatGPT usage discovery for isolated host applications.

### 🐛 Fixes

- Detects newly created Antigravity Cockpit ChatGPT data instances on the next sync instead of waiting for the 24-hour discovery cache to expire.
- Correctly imports token usage from newly created isolated Codex homes while preserving per-model attribution, including third-party models used through the Codex runtime.

### 📦 Installation

**Recommended:** Download `TokenViewer.dmg`
- Drag `TokenViewer.app` to `/Applications`
- First launch: System Settings -> Privacy & Security -> Open Anyway
- Requires macOS 14 (Sonoma) or later

**Alternative:** Download `TokenViewer-Installer.pkg`
- Double-click to install -> app is placed in `/Applications`
- The installer updates the existing app in place and opens it after installation
- Requires macOS 14 (Sonoma) or later
