## TokenViewer v0.3.15

This release improves session launching on macOS Apple silicon and Intel.

### macOS: open sessions in their original app

- Recognize sessions created by the ChatGPT desktop app and open them directly in ChatGPT instead of starting a CLI resume command.
- Open the parent conversation for Codex subagent sessions, including nested subagents, to avoid errors when a child cannot resume independently. Ordinary forks continue to open their own conversation.
- Show whether a session opens in ChatGPT or opens its parent. Report missing or invalid parent sessions instead of attempting an unsupported resume.
- Add a "Prefer Original Application" setting, enabled by default. CLI sessions and unrecognized origins continue to use the configured terminal or workspace.
- Preserve the original Codex home for isolated accounts. Desktop navigation retains the app's existing permission settings rather than applying terminal YOLO arguments.
- Keep terminal commands conditional on successfully entering the working directory.

### Windows x64

The Windows package is rebuilt for this version. The session-launch improvements above apply to macOS.

### Downloads

- Apple silicon, macOS 14+: `TokenViewer.dmg`, `TokenViewer-Installer.pkg`, or `TokenViewer-0.3.15-macOS-arm64.zip`.
- Intel, macOS 14+: `TokenViewer-0.3.15-macOS-x64.dmg`, `TokenViewer-0.3.15-macOS-x64-Installer.pkg`, or `TokenViewer-0.3.15-macOS-x64.zip`.
- Windows 10/11 x64: extract `TokenViewer-0.3.15-Windows-x64.zip` and run `TokenViewer.exe`.

macOS packages use self-signed packaging. The Windows build is unsigned.
