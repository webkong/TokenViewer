## TokenViewer v0.2.19

This release makes shared Skill library moves reliable and adds clearer model cost details to the macOS app.

### ✨ Improvements

- Shows a detailed token and cost breakdown when hovering over model usage costs.
- Stores TokenViewer's Skill Manager configuration in its private application data directory instead of the shared Agent directory.

### 🐛 Fixes

- Preserves all valid Agent Skill symlinks when moving the shared Skills directory, including links created outside TokenViewer.
- Supports both absolute and relative Skill symlinks during directory migration.
- Avoids silently skipping Agent directories when a symlink scan cannot be completed.

### 📦 Installation

**Recommended:** Download `TokenViewer.dmg`
- Drag `TokenViewer.app` to `/Applications`
- First launch: System Settings -> Privacy & Security -> Open Anyway
- Requires macOS 14 (Sonoma) or later

**Alternative:** Download `TokenViewer-Installer.pkg`
- Double-click to install -> app is placed in `/Applications`
- The installer updates the existing app in place and opens it after installation
- Requires macOS 14 (Sonoma) or later
