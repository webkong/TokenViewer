## TokenViewer v0.3.8

This release adds encrypted device sync over WebDAV, improves Skill management, and fixes Windows rollback handling for synchronized Agent links.

### Device Sync

- Added the device-sync foundation for securely sharing TokenViewer data between computers through a user-configured WebDAV server.
- Added encrypted vault creation, joining, recovery, and previewed push/pull workflows in Settings.
- Improved WebDAV compatibility by using recursive `Depth: 1` directory listing and clearer retry guidance for provider errors.
- Fixed Windows rollback so directory and file links retain their correct type when an apply operation fails.

### Skills

- GitHub Skill installation now supports authenticated sparse clones for private repositories.
- Skill installation forms use the available width more consistently.
- Directories containing child Skills are now selected, assigned to Agents, synchronized, organized, restored, and deleted as one unit. Child Skills remain available for content preview.
- Filtered Git pushes preserve unselected remote Skills and root files without restoring content intentionally deleted from the local worktree.
- Reorganized detail actions into a stable hierarchy with a separate destructive action area.
