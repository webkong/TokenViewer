## TokenViewer v0.3.6

This release fixes duplicated model rows caused by inconsistent model-name casing across agents.

### Fixes

- Model usage is no longer split into duplicate entries when different agents report the same model with different letter casing (for example `GLM-5.3-Flash` vs `glm-5.3-flash`). Model IDs are now normalized (trimmed and lowercased) before storage and aggregation.
- Existing databases are upgraded in place: case-variant rows are merged with their token counts preserved, and newly synced data is stored in canonical lowercase form. No re-sync or manual action is required.
