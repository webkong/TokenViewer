## TokenViewer v0.3.5

This release improves model cost accuracy and makes estimated costs clearer across macOS and Windows.

### Pricing accuracy

- Current model prices now prefer the latest available LiteLLM pricing data, with bundled offline fallbacks when online pricing is unavailable.
- Historical usage is priced using the rate that applied at the time for GPT-5.6, Claude Sonnet 5, and DeepSeek V4 price changes.
- Free model variants remain correctly priced at zero, including when their names resemble paid models.

### Improvements

- Cost labels now clearly identify values as API-equivalent estimates rather than subscription charges.
- Model matching now handles GPT-5.6 reasoning-level suffixes more reliably.

### Downloads

**macOS 14 or later (Apple silicon)**
- `TokenViewer.dmg` - stable Apple silicon DMG download.
- `TokenViewer-Installer.pkg` - stable Apple silicon installer download.
- `TokenViewer-0.3.5-macOS-arm64.zip` - portable Apple silicon app archive.

**macOS 14 or later (Intel)**
- `TokenViewer-0.3.5-macOS-x64.dmg` - Intel Mac disk image.

**Windows 10/11 x64**

macOS packages currently use self-signed packaging. The Windows build is currently unsigned.
