## TokenViewer v0.2.21

This release makes Skills Git synchronization safer, prevents unnecessary Kiro limits requests, and adds native Intel Mac packages.

### ✨ Highlights

- Adds dedicated macOS Intel x64 DMG, ZIP, and PKG artifacts alongside Apple silicon and Windows packages.
- Safe Skills pull now preserves tracked and untracked local changes while integrating remote updates.
- Safe Skills push commits local changes, integrates remote commits, and pushes without force-updating shared history.
- Adds explicit force pull and force push actions for cases where replacing local or remote state is intentional.

### 🐛 Fixes

- Stops Kiro limits checks from launching `kiro-cli /usage` when the local CLI login token is absent.
- Treats a saved Kiro device registration without an account token as logged out on both macOS and Windows.

### 📦 Downloads

**macOS 14 or later (Apple silicon)**
- `TokenViewer.dmg` — stable Apple silicon DMG download.
- `TokenViewer-Installer.pkg` — stable Apple silicon installer download.
- `TokenViewer-0.2.21-macOS-arm64.zip` — portable Apple silicon app archive.

**macOS 14 or later (Intel)**
- `TokenViewer-0.2.21-macOS-x64.dmg` — Intel Mac disk image.
- `TokenViewer-0.2.21-macOS-x64-Installer.pkg` — Intel Mac installer.
- `TokenViewer-0.2.21-macOS-x64.zip` — portable Intel Mac app archive.

**Windows 10/11 x64**
- `TokenViewer-0.2.21-Windows-x64.zip` — extract the archive and run `TokenViewer.exe`.

macOS packages currently use self-signed packaging. The Windows build is currently unsigned.
