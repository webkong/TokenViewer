## TokenViewer v0.3.13

This release makes Skill Git conflicts easier to resolve on macOS and improves usage synchronization reliability across all platforms.

### macOS: Skill Git sync

- Preview local and remote changes before synchronizing. Resolve conflicts per file by choosing the local version, the remote version, or editing manually.
- Resume saved conflict choices after restarting. Unresolved conflicts never overwrite active Skills or get published.
- Keep recovery snapshots and safely resume interrupted synchronization. Publishing uses a non-force push and checks for changes made since the preview.
- Preserve unselected local changes during filtered uploads and apply selected merged files correctly. Complex rename or file/directory conflicts require a Git client.

### Shared core: macOS Apple silicon, macOS Intel, and Windows x64

- Commit usage records and parser checkpoints together to prevent duplicate counting after interrupted writes.
- Rebuild usage data atomically, retaining existing data when parsing fails.
- Recover usage data when device-sync application fails or is interrupted.
- Detect ZCode usage written through SQLite WAL without relying on the database file's modification time.

### macOS feedback

- Report usage synchronization failures instead of showing a premature success message.

Versions 0.3.11 and 0.3.12 did not publish because a Git regression test assumed LF line endings on Windows. This release explicitly tests CRLF checkouts while retaining the content, clean-worktree, and repeat-sync checks.

### Downloads

- Apple silicon, macOS 14+: `TokenViewer.dmg`, `TokenViewer-Installer.pkg`, or `TokenViewer-0.3.13-macOS-arm64.zip`.
- Intel, macOS 14+: `TokenViewer-0.3.13-macOS-x64.dmg`, `TokenViewer-0.3.13-macOS-x64-Installer.pkg`, or `TokenViewer-0.3.13-macOS-x64.zip`.
- Windows 10/11 x64: extract `TokenViewer-0.3.13-Windows-x64.zip` and run `TokenViewer.exe`.

macOS packages use self-signed packaging. The Windows build is unsigned.
