## TokenViewer v0.2.17

This release improves skill management and fixes duplicated ChatGPT usage from forked Codex sessions.

### ✨ Improvements

- Organizes related skills into clearer groups for easier browsing and management.
- Makes skill installation and metadata cleanup more reliable across supported skill environments.
- Improves skill list actions and installation feedback in the macOS app.

### 🐛 Fixes

- Prevents forked Codex sessions from double-counting ChatGPT token usage.

### 📦 Installation

**Recommended:** Download `TokenViewer.dmg`
- Drag `TokenViewer.app` to `/Applications`
- First launch: System Settings -> Privacy & Security -> Open Anyway
- Requires macOS 14 (Sonoma) or later

**Alternative:** Download `TokenViewer-Installer.pkg`
- Double-click to install -> app is placed in `/Applications`
- The installer updates the existing app in place and opens it after installation
- Requires macOS 14 (Sonoma) or later
