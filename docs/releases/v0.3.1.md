## TokenViewer v0.3.1

This release makes agent installation detection more reliable: Claude Code and ChatGPT (Codex) are now recognized from their runtime data, and CLI presence checks cover Homebrew and user-local paths for apps launched outside a shell.

### ✨ Highlights

- Claude Code is now detected from runtime data (`~/.claude/projects`, history, and settings), not only from a skills directory.
- ChatGPT (Codex) is now detected from its sessions and config (`~/.codex/sessions`, `~/.codex/config.toml`).
- CLI presence checks now also search Homebrew (`/opt/homebrew/bin`, `/usr/local/bin`) and user-local bin directories, so agents are detected correctly when TokenViewer is launched from Finder with a minimal PATH.

### 📦 Downloads

**macOS 14 or later (Apple silicon)**
- `TokenViewer.dmg` — stable Apple silicon DMG download.
- `TokenViewer-Installer.pkg` — stable Apple silicon installer download.
- `TokenViewer-0.3.1-macOS-arm64.zip` — portable Apple silicon app archive.

**macOS 14 or later (Intel)**
- `TokenViewer-0.3.1-macOS-x64.dmg` — Intel Mac disk image.
- `TokenViewer-0.3.1-macOS-x64-Installer.pkg` — Intel Mac installer.
- `TokenViewer-0.3.1-macOS-x64.zip` — portable Intel Mac app archive.

**Windows 10/11 x64**
- `TokenViewer-0.3.1-Windows-x64.zip` — extract the archive and run `TokenViewer.exe`.

macOS packages currently use self-signed packaging. The Windows build is currently unsigned.
