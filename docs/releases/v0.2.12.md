## TokenViewer v0.2.12

This release expands Skills management with safer directory migration, nested organization, and secure environment variable configuration.

### ✨ Improvements

- Added environment variable detection and management for Skills, including required and secret values stored securely in the macOS Keychain.
- Added a searchable environment variable manager, with per-Skill configuration available directly from Skill details.
- Improved nested Skill directory support by preserving bundle paths and grouping related Skills in the list.

### 🐛 Fixes

- Changing the shared Skills directory can now move existing content, relink installed Skills, and request confirmation before replacing an existing destination.
- Prevented invalid moves between nested source and destination directories.
- Clarified that Kiro local logs do not expose cache-token accounting, so cache usage cannot be reconstructed by TokenViewer.

### 📦 Installation
**Recommended:** Download `TokenViewer.dmg`
- Drag `TokenViewer.app` to `/Applications`
- First launch: System Settings -> Privacy & Security -> Open Anyway
- Requires macOS 14 (Sonoma) or later

**Alternative:** Download `TokenViewer-Installer.pkg`
- Double-click to install -> app is placed in `/Applications`
- The installer updates the existing app in place and opens it after installation
- Requires macOS 14 (Sonoma) or later
