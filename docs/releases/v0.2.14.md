## TokenViewer v0.2.14

This release improves ChatGPT data discovery and Skills environment configuration.

### ✨ Improvements

- Automatically discovers ChatGPT data directories used by the default CLI, Orca, Antigravity Cockpit, and other isolated host applications.
- Added a ChatGPT data directory settings panel for reviewing discovered locations, adding custom directories, and rescanning.
- Uses a shared discovery result for local token usage and live ChatGPT quota tracking.
- Shows detected default values for Skill environment variables before saving, making configuration easier to review and edit.

### 🐛 Fixes

- Prevents duplicated ChatGPT usage when the same rollout is copied or linked across multiple isolated data directories.
- Preserves compatibility with existing path-based ChatGPT parser cursors during migration.

### 📦 Installation

**Recommended:** Download `TokenViewer.dmg`
- Drag `TokenViewer.app` to `/Applications`
- First launch: System Settings -> Privacy & Security -> Open Anyway
- Requires macOS 14 (Sonoma) or later

**Alternative:** Download `TokenViewer-Installer.pkg`
- Double-click to install -> app is placed in `/Applications`
- The installer updates the existing app in place and opens it after installation
- Requires macOS 14 (Sonoma) or later
