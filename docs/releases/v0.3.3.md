## TokenViewer v0.3.3

This release fixes duplicated DeepSeek Harness usage after forking a session, makes update checks resilient to expired GitHub credentials, and improves session launching when a saved working directory no longer exists.

### 🛠 Fixes

- DeepSeek Harness forked sessions no longer count the copied parent history twice; only usage generated after the fork is added.
- Existing usage is rebuilt once from local source logs so previously duplicated DeepSeek Harness totals are corrected automatically.
- Update checks retry anonymously when a saved GitHub token has expired or been revoked.
- Sessions with missing working directories are validated asynchronously and now show clearer launch availability and guidance.
