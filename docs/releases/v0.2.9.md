## TokenViewer v0.2.9

This release makes Skills Git synchronization safer and more predictable, improves large Skill previews, and adds a Yesterday usage filter.

### 🐛 Fixes
- Fixed Git sync status so local edits and newly added Skills are detected reliably on the configured branch.
- Fixed filtered synchronization so unselected remote Skills remain unchanged.
- Fixed performance issues when opening large Skill details by preloading `SKILL.md` and loading additional files on demand.

### ✨ Improvements
- Replaced merge-based Skills synchronization with explicit Force Pull and Force Push actions, with confirmation before local or remote content is overwritten.
- Added a configurable Git branch for Skills synchronization, defaulting to `main`.
- Added global filtering and improved cross-agent organization for shared Skills.
- Added a confirmation flow when changing the shared Skills source directory.
- Added Yesterday as a quick date-range filter.

### 📦 Installation
**Recommended:** Download `TokenViewer.dmg`
- Drag `TokenViewer.app` to `/Applications`
- First launch: System Settings -> Privacy & Security -> Open Anyway
- Requires macOS 14 (Sonoma) or later

**Alternative:** Download `TokenViewer-Installer.pkg`
- Double-click to install -> app is placed in `/Applications`
- The installer updates the existing app in place and opens it after installation
- Requires macOS 14 (Sonoma) or later
