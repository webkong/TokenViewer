## TokenViewer v0.2.13

This release updates ChatGPT quota tracking and product naming.

### ✨ Improvements

- Renamed the user-facing Codex provider to ChatGPT while preserving existing local Codex CLI data and configuration.
- Updated the website and documentation to use the unified ChatGPT name.

### 🐛 Fixes

- Added ChatGPT Business monthly quota support with the correct monthly reset countdown.
- Removed the misleading subscription-expiry badge for renewable ChatGPT Business entitlements.

### 📦 Installation

**Recommended:** Download `TokenViewer.dmg`
- Drag `TokenViewer.app` to `/Applications`
- First launch: System Settings -> Privacy & Security -> Open Anyway
- Requires macOS 14 (Sonoma) or later

**Alternative:** Download `TokenViewer-Installer.pkg`
- Double-click to install -> app is placed in `/Applications`
- The installer updates the existing app in place and opens it after installation
- Requires macOS 14 (Sonoma) or later
