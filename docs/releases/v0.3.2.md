## TokenViewer v0.3.2

This release adds per-model token breakdowns to the usage dashboard: hover any model or agent bar to see how its tokens split across input, output, and cache, and the Sessions tab now shows a proper loading state while it scans.

### ✨ Highlights

- Model and Agent breakdown rows now surface input / output / cache token counts in a hover popover.
- The Sessions tab shows a loading indicator while scanning, and warms its cache in the background on launch for a faster first open.
