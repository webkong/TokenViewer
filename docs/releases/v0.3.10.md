## TokenViewer v0.3.10

This release fixes Skill environment paths that could remain literal strings and create directories in the wrong location.

### Fixes

- Recognized directory environment variables safely expand leading `~`, `$HOME`, and `${HOME}` before saving. Shell exports and stored metadata stay consistent, including values applied through device sync.
- Ordinary environment values remain literal and safely quoted; no shell expressions are evaluated.
- Skill storage settings, Finder actions, installation, and the shared core's startup configuration validate paths before creating directories. Unresolved variables and relative persistent-storage paths are rejected.
- Windows short filenames containing a literal `~` remain valid, including temporary directories used for Skill installation and device sync.
- macOS Skill settings show a clear validation message for invalid directory paths.
- Hardened macOS signing scripts against invalid directory overrides and misleading home-directory prefixes.

The shared-core fixes apply to macOS Apple silicon, macOS Intel, and Windows x64. The Skill editor and signing changes apply to macOS. Version 0.3.9 did not publish because its Windows checks failed; this release includes that compatibility fix.
