## TokenViewer v0.2.20

This release brings TokenViewer to Windows, adds DeepSeek Harness usage tracking, and unifies cross-platform releases.

### ✨ Highlights

- Adds a native Windows application with usage dashboards, charts, settings, limits, localization, and shared Rust-core data processing.
- Adds DeepSeek Harness (DSH) usage parsing, Agent metadata, and branding.
- Adds DeepSeek V4 peak and off-peak pricing support.

### 🐛 Fixes

- Improves Windows localization bindings, chart resource initialization, Git fixture handling, and cross-platform test reliability.
- Preserves Skills symlinks correctly on Windows and improves Agent installation detection.
- Makes DSH incremental frame parsing resilient while limiting decompression work per sync.

### 📦 Downloads

**macOS 14 or later (Apple silicon)**
- `TokenViewer.dmg` — drag the app to `/Applications`.
- `TokenViewer-Installer.pkg` — installs and updates the app in `/Applications`.
- The app currently uses self-signed packaging; on first launch, allow it in System Settings → Privacy & Security if prompted.

**Windows 10/11 x64**
- `TokenViewer-0.2.20-Windows-x64.zip` — extract the archive and run `TokenViewer.exe`.
- The Windows build is currently unsigned, so Microsoft Defender SmartScreen may ask for confirmation.

### 🔧 Release automation

- A pushed `vX.Y.Z` tag now builds and validates both macOS and Windows packages before publishing one atomic GitHub Release.
- Stable macOS download aliases are retained for the website and README links.
